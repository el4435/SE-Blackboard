EXECUTIVE SUMMARY
============================================================

1. Fallback apply (diff mode):
   - BB: 7/20 -> 8/20 (+5pp)
   - MP: 5/20 -> 5/20 (+0pp)
   - Hybrid: 6/20 -> 6/20 (+0pp)
   -> Fallback apply provides marginal improvement for BB

2. Whole-file mode:
   - BB: 7/20 -> 3/20 (-20pp)
   - MP: 5/20 -> 4/20 (-5pp)
   -> Whole-file mode HURTS performance (WORSE than baseline)
   -> Root cause: extract_file_blocks() fails for all non-Django repos

3. Best overall config: BB + diff + fallback
   - 8/20 (40%) Easy issues resolved
   - vs baseline BB + diff + strict: 7/20 (35%)
   - Improvement: +5pp

4. Phase 3 recommendation: STOP whole-file experiments
   - Whole-file mode is counterproductive
   - Fallback apply is the only beneficial change
   - BB effect (+15pp with fallback) remains the strongest signal
