# 1. Introduction

The rapid advancement of large language models (LLMs) [Brown et al., 2020] has catalyzed the emergence of multi-agent systems for software engineering (SE). Systems such as MetaGPT [Hong et al., 2024], ChatDev [Qian et al., 2024], SWE-Agent [Yang et al., 2024], and AgentCoder [Huang et al., 2024] demonstrate that multiple AI agents, each assigned a specialized role, can collaboratively tackle complex software development tasks including code generation [Chen et al., 2021], bug fixing, and code review. These systems represent a paradigm shift from monolithic LLM-based tools toward modular, role-based architectures that mirror human software development workflows.

Despite their promise, current multi-agent SE systems share a common architectural assumption: **message-passing communication**. In this model, agents communicate by forwarding natural language messages along a predefined chain---the output of one agent becomes the input of the next. While intuitive and simple to implement, this approach suffers from a fundamental limitation: information fidelity degrades at each handoff. When a Planner agent summarizes an issue description for a Coder agent, critical technical details---function signatures, parameter types, error stack traces, and specific code locations---may be paraphrased, simplified, or omitted entirely. This progressive information degradation, which we term *knowledge drift*, has been identified as a primary failure mode in multi-agent LLM systems [Zhang et al., 2025].

The knowledge drift problem is particularly acute in software engineering contexts. Unlike general reasoning tasks where paraphrasing may preserve semantic equivalence, SE tasks demand exact technical precision: a single character difference in a function name or file path can determine whether a patch applies correctly. When a Planner's analysis states "modify the `get_queryset` method in the `ModelAdmin` class" but the Coder receives only "fix the admin query method," the resulting patch is likely to target incorrect code. This precision requirement makes SE an ideal domain for studying information preservation in multi-agent architectures.

Existing approaches to communication quality in multi-agent systems have focused primarily on post-hoc remediation. RTADev [Fang et al., 2025] proposes intention alignment techniques to verify that agents' interpretations match the original intent, but this approach detects information loss only after it has occurred. What is missing is a *proactive* architectural solution that prevents information degradation by design. The Blackboard architecture---a classical AI pattern featuring a shared workspace accessible to all agents [Nii, 1986]---offers precisely this capability. Recent work has demonstrated Blackboard's effectiveness in reducing information loss for LLM-based reasoning [Wang et al., 2025] and data science [Salemi et al., 2025] tasks, but it has never been applied to software engineering.

This paper makes the following contributions:

1. **SE-Blackboard Framework**: We introduce the first application of the Blackboard shared-state architecture to multi-agent software engineering, implementing a modular framework that supports three pluggable communication modes (Message-Passing, Blackboard, and Hybrid) within identical agent pipelines.

2. **Information Fidelity Score (IFS)**: We propose a novel metric that quantifies the preservation of key technical entities (function names, class names, file paths, error messages) across pipeline stages, enabling fine-grained measurement of information retention independent of downstream task success.

3. **Controlled Empirical Evaluation**: We conduct experiments on 50 SWE-bench Lite issues, demonstrating that the Blackboard architecture improves Coder-stage IFS by 50% (0.584 vs. 0.390, $p=0.058$) and resolve rate by 4 percentage points (16% vs. 12%), while identifying patch formatting as the primary bottleneck limiting further gains.

4. **Open-Source Framework**: We release a modular multi-agent SE framework with pluggable communication architectures, structured state schemas, and comprehensive logging, designed to facilitate future research on agent communication in SE.

The remainder of this paper is organized as follows. Section 2 reviews related work on multi-agent SE systems, communication architectures, and the Blackboard pattern. Section 3 describes the SE-Blackboard system design, including the state schema, communication modes, and agent architecture. Section 4 details the experimental setup. Section 5 presents the results, including resolve rate, IFS analysis, failure analysis, and a case study. Section 6 discusses the implications and limitations of our findings. Section 7 addresses threats to validity, and Section 8 concludes with directions for future work.
